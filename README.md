# Проект "Маска"
## Описание:
Проект "Маска" - это банковское приложение на Python созданное для маскировки номеров банковских карт пользователей.
## Установка:
1.Клонируйте репозиторий: git clone https://github.com/ALVO-bot/PythonProject_new.git
2.2. Установите зависимости: pip install -r requirements.txt
## Использование:
1. Откройте приложение в вашем браузере.
2. Создайте новый проект и начните добавлять задачи.
